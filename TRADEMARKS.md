# The aegis name

aegis's code is under the [MIT License](LICENSE): you may use, copy, change and redistribute it, including in your own products. This policy is about the **name**, which the MIT License does not cover. It does not limit anything the license allows.

"aegis" as the name of this tool, the package name `aegis` on pub.dev and the GitHub Action "Aegis Mobile Security Audit" identify the official project at [github.com/khaledSayedAbdellah/aegis](https://github.com/khaledSayedAbdellah/aegis) and its releases on [pub.dev/packages/aegis](https://pub.dev/packages/aegis).

## Without asking

* Say that your tool, pipeline or report uses aegis, or that a project was audited with aegis.
* Write about aegis, teach it, compare it with other tools, and link to it.
* Use the unchanged official releases under their own name, in any project, commercial or not.

## Forks and modified versions

You may publish a fork or a modified version, under the MIT License, if you:

* **give it a different name**, one that can't be mistaken for aegis, on pub.dev, GitHub Marketplace, app stores and anywhere else you publish it;
* **keep the copyright notice and the LICENSE file**, as the MIT License requires;
* **say that it is based on aegis** and link to this repository, for example in its README: "Based on [aegis](https://github.com/khaledSayedAbdellah/aegis) by Khaled Sayed";
* **don't present it as aegis**, as an official release, or as endorsed by this project.

## Reporting misuse

A package, action or app that copies aegis without the copyright notice, or that presents itself as aegis, can be reported to the platform that hosts it, for example with **Report package** on pub.dev or GitHub's [DMCA takedown](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy) process. To report one to the maintainer, open an [issue](https://github.com/khaledSayedAbdellah/aegis/issues).

Questions about using the name: open an issue before you publish.
